# Motorcycle Parts Inventory and Sales Management System

A 10-week college project for managing motorcycle parts, inventory movements, cashier sales, users, and reports.

## Current phase

Phase 2: Design Preparation / Initial Development. The repository contains a Vue 3 + Vite prototype and a Laravel 12 API foundation with Sanctum installed.

See [docs/PHASE-2-ARCHITECTURE.md](docs/PHASE-2-ARCHITECTURE.md) for the architecture, ERD, API plan, roles, and setup commands.

## Run the prototype

```powershell
cd frontend
npm run dev
```

The Laravel API foundation can be started with:

```powershell
cd backend
php artisan serve
```

The database connection remains a Phase 3 task until the migrations are implemented.
